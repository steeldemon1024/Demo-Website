# SMASH & BUN

A responsive, single-page restaurant site for the fictional SMASH & BUN burger restaurant.

Open \`index.html\` in a browser to preview it locally.

## Content and assets

- All menu copy, prices, address and hours are collected near the markup in \`index.html\`.
- The food and interior photography uses remote, high-quality placeholder image URLs. Replace the image \`src\` values in \`index.html\` with the restaurant's licensed photography when it is available.
- \`app.js\` provides the mobile navigation, accessible order tray, quantity controls, and add-to-order feedback.
